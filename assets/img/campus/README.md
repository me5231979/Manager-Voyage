# Campus photos for the training videos

Drop real Vanderbilt photographs here (JPEG, 1920px wide or larger, landscape).
Once they are on `main`, each one is reachable at

    https://raw.githubusercontent.com/me5231979/Manager-Voyage/main/assets/img/campus/<file>.jpg

and can be handed to Runway as the start frame for an image-to-video clip
(`scripts/build-media.py` then stitches the clip into the course videos via
`.github/media-urls.json`). Photos supplied by FLH are preferred over the
Wikimedia Commons images used for the first pass (Kirkland Hall, CC BY 4.0;
E. Bronson Ingram College).
