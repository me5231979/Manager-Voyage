    The survey and the completion record

    One Power Automate flow, two payloads, one SharePoint list.

    The survey page and the week-four completion button both post JSON to one flow URL, the same way the Foundations course posts its assessment. Until the URL is set, the site keeps a local copy and offers email.

    1

    Create the flow

    Power Automate, new instant cloud flow, trigger “When an HTTP request is received”, anyone can trigger. Leave the schema empty. Copy the HTTP POST URL into cohort/program.js under links.surveyFlowUrl.

    2

    Read the body

    The site posts as text/plain so no browser preflight is needed. In the flow, add a Compose step with the expression json(base64ToString(triggerBody()?['$content'])). Every field is then available: event (survey or completion), at, week, the ten answers by key, area, name, email.

    3

    Write to SharePoint

    Condition on event. For survey: Create item in a Cohort Survey list with one column per question key. For completion: Create item in a Cohort Completions list with name, email, area, segments done, labs, pulse, indicators, and the Playbook lines. Optional: send the manager a copy by email.

    Survey keys: week, overall, useful, least, practice, pace, facilitation, monday, recommend, comments, name, email, area, team_type. Completion keys: segments_done, segments_total, labs, pulse, indicators, philosophy, team_goal, first_move, reassess_date, who.

    Review status

    The scenario scripts are drafts until reviewed.

    The lab briefs, the role cards, and the five voice agents were written for this build. Before a room sees them, a subject-matter expert and Employee Relations read them. Until both have, say so in the room: these are practice characters, not policy.

    SME

    Subject-matter expert

    Reads the eight area vocabularies for plausibility: dining, IT, facilities, lab, library, student affairs, administration, advancement. Flags anything a real supervisor in that area would not say.

    Status: pending. Set review.sme to true in cohort/program.js when done.

    ER

    Reads the five labs for the line between a performance conversation the manager owns and a matter that must route the same day. Confirms the wording of the routing line on every score panel.
